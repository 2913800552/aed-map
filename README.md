# 山东省 AED 急救地图

这是 AED 使用平台中的地图查找功能，展示济南市和淄博市的 AED 点位分布。

在线地图：[https://2913800552.github.io/aed-map/](https://2913800552.github.io/aed-map/)

## 资料说明

| 仓库文件 | 中文内容说明 |
| --- | --- |
| `index.html` | 网站首页与 AED 交互地图 |
| `data/shandong-aed-points.json` | 济南市、淄博市 AED 点位明细，包括名称、区县、经纬度、场所类别和数据来源 |
| `data/shandong-aed.json` | 城市及区县点位数量、地图中心和范围等统计信息 |
| `data/shandong-aed-clusters.json` | 地图点位聚合索引，用于提升地图显示速度 |
| `vendor/` | 地图页面运行所需的本地程序资源 |

## 当前数据量

- 全部点位：4,479 条
- 济南市：2,531 条
- 淄博市：1,948 条

核心运行文件保留英文文件名，避免修改后影响网页和数据加载；中文内容说明统一放在本页，打开仓库即可查看。
